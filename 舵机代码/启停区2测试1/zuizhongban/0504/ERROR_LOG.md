# 错误记录

## [2026-10-08] 回退到每82cm进行陀螺仪姿态修正的版本

**现象**：后续版本加入了保持工位朝向、BFS拐角提前对准目标工位以及到站跳过重复转向，实际运行逻辑偏离了用户指定的82cm姿态修正版基线。

**原因**：在82cm分段修正完成后，又继续叠加了 `CoarseTravelYaw`、`CoarseDestinationYawReady` 和地图方向到车体方向换算逻辑。

**修复**：后续代码全部以停用注释保留；恢复每段BFS开始前按道路方向转向，按地图方向行驶，最多每两格（82cm）停车一次，并使用 `Rotation(DirToYaw(dir))` 读取陀螺仪闭环修正；到站恢复按 `Task.StationYaw` 对准工位。

**验证**：82cm专项测试及其余11组基线回归测试全部通过；Keil完整构建 `0 Error(s), 3 Warning(s)`，3条警告均为 `move.c` 原有不可达 `break`。

## [2026-10-08] 粗加工区到暂存区发生重复转向

**现象**：车辆在粗加工区完成机械臂朝向 `+Y` 的对准后，前往暂存区时会在离站或到站阶段执行多余转向；实际要求是第一段保持当前姿态沿地图 `+X` 平移，只在BFS拐角转一次，到达暂存区时机械臂自然朝向 `+X`。

**原因**：旧流程没有区分“保持工位姿态的第一段平移”和“拐角处对准目标工位朝向”，并且到站阶段仍可能无条件再次调用 `Rotation(Task.StationYaw)`。

**修复**：增加 `CoarseDestinationYawReady` 状态。第一段直线保持粗加工区离站姿态；从第二段直线开始前，仅在BFS拐角执行一次 `Rotation(Task.StationYaw)`，成功后记录目标朝向已就绪；到达暂存区后检查该状态，已经对准则跳过重复转向。新任务、故障和任务完成时均清除该状态。旧实现按规则注释保留。

**验证**：工位朝向保持、82cm姿态检查、IMU闭环旋转、启动区校正、地图方向映射、粗定位流程及BFS安全等共13组PowerShell回归测试全部通过；Keil完整构建 `0 Error(s), 3 Warning(s)`，3条警告均为 `move.c` 原有不可达 `break`。

## [2026-10-08] 粗加工区机械臂对准后离站又多转180度

**现象**：车辆到达粗加工区 `(2,4)` 后，机械臂已经一次对准目标方向；停留结束准备前往暂存区时，底盘又发生一次明显旋转。

**原因**：粗加工区到站姿态为 `yaw=180°`，但旧`RunMap()`在下一段BFS开始时强制把地图X轴运动统一转到`yaw=0°`，因此离站时额外旋转180°。

**修复**：旧的“每段BFS强制转道路固定朝向”逻辑注释保留；到站对准成功后保存当前工位朝向，后续BFS根据保存的`0/-90/90/180°`将地图方向换算成车体前后左右，利用麦轮平移寻路，不再旋转车身。每82cm的姿态复核也校正到保存的工位朝向；只有到达下一站时才执行下一次机械臂朝向对准。

**验证**：新增工位朝向保持回归测试，连同原有测试共13组全部通过；Keil完整构建 `0 Error(s), 3 Warning(s)`，3条警告均为 `move.c` 原有不可达 `break`。

## [2026-10-08] BFS连续行驶超过82cm时没有定期校正姿态

**现象**：BFS会把连续同方向网格合并成一次长距离运动，车辆可能连续行驶超过82cm，中途没有强制读取陀螺仪并校正姿态。

**原因**：`RunMap()`使用`UNIT_DIS * combo`一次执行整段同方向路径，仅在整段开始前转向；连续路线较长时没有82cm检查点。

**修复**：旧整段执行代码注释保留；同方向路线拆为最多2格一段，即最大`41cm * 2 = 82cm`。每走满82cm后调用`Rotation(DirToYaw(dir))`，等待新IMU帧并校正到本段绝对目标朝向；校正失败立即停止四轮、清除路径并返回失败，由粗定位状态机进入故障。

**验证**：新增82cm姿态校正回归测试，连同原有测试共12组全部通过；Keil完整构建 `0 Error(s), 3 Warning(s)`，3条警告均为 `move.c` 原有不可达 `break`。

## [2026-10-08] 转向未等待陀螺仪到位且旋转伴随底盘位移

**现象**：车辆发生转向时，陀螺仪没有稳定检测到目标角度；车身旋转过程中还会产生一定平移，随后状态机可能在未对准时继续行驶。

**原因**：`Rotation()` 首次5°检测失败后会把静态 `imu_ok` 永久锁定为无效并改走开环；`TurnIMU()` 在电机动作后没有等待新IMU帧，只读旧 `yaw` 且最多补偿一次。旋转速度78、单次最大90°也会加重麦轮打滑和四轮响应差造成的转动中心偏移。

**修复**：旧实现使用 `#if 0` 保留；取消永久IMU状态缓存和开环回退，所有转向在动作前后均等待连续有效新帧，连续两次无角度响应或超时立即停止并返回失败；`TurnIMU()`统一调用闭环`Rotation()`，BFS、启动/停止校正及到站对准均检查失败状态；旋转速度由78降至45，单次修正由90°限制为30°。

**验证**：新增旋转IMU反馈回归测试，连同原有测试共11组全部通过；Keil完整构建 `0 Error(s), 3 Warning(s)`，3条警告均为 `move.c` 原有不可达 `break`。实际平移量仍需以5°、10°小角度实车测试确认。

## [2026-10-08] S2转向正确但从BFS入口沿+Y驶出地图

**现象**：S2启动校正完成后，车辆按预期顺时针旋转准备从 `(0,4)` 前往二维码区 `(0,2)`，但平移时沿地图 `+Y` 驶出场地；S1同样存在首段向 `-X` 的风险。

**修复**：保留旧代码注释；将地图 `+X/-X/+Y/-Y` 的横移符号分别改为 `-1/+1/+1/-1`，不改已实测正确的四轮分解公式和旋转角；S1启动改为 `LEFT 5cm -> LEFT 20cm -> FRONT 25cm`，回程改为 `BACK 25cm -> RIGHT 25cm`。每段BFS移动先走5cm并暂停1500ms，再补足剩余距离。

**验证**：新增地图方向映射回归测试，连同原有测试共10组全部通过；Keil完整构建 `0 Error(s), 3 Warning(s)`，3条警告均为 `move.c` 原有不可达 `break`。麦轮照片未发现需要修改四轮分解公式的安装异常，最终方向以5cm实车复测为准。

## [2026-08-28] 启动和停止校正可能在IMU数据就绪前开始

**现象**：启动校正感觉陀螺仪还未校正完成就进入BFS；任务结束返回启停区时，停止校正也可能出现轮子动作异常。

**原因**：启动和停止校正直接调用 `Rotation(0)`，没有确认IMU已经收到有效的新数据。上电后或通信暂时中断时，`yaw` 可能保留默认值或旧值，导致 `Rotation(0)` 误判已经到位或按旧角度动作。

**修复**：IMU模块增加连续3帧有效数据判定；启动和停止校正前均调用 `Imu_Wait_Ready(1500)`，每次强制等待新数据。超时后不旋转、不进入下一阶段，保持原状态并在下一轮重新等待。

## [2026-08-28] BFS起步时地址1、2电机提前运动

**现象**：刚进入BFS寻路时，地址1、2电机先运动，视觉上像转得更快；随后四个电机恢复正常。

**原因**：`RunMove()` 和 `Rotate()` 原来按地址1到4依次发送位置帧，且同步标志 `snF=0`，每个驱动器收到帧后立即启动；地址1、2因此比地址3、4提前约20～30ms。

**修复**：四个位置帧统一改为 `snF=1`，先缓存不执行；四帧发送完成后调用 `Emm_V5_Synchronous_motion(0)`，通过地址0广播同步触发。旧版立即启动代码保留在函数注释中。

## [2026-08-29] 正式搬运入口与粗定位状态机同时驱动

**现象**：设置搬运任务并点击开始后，启动校正尚未完整结束就进入 BFS；回航时停止校正也可能与其他任务逻辑抢占电机。

**原因**：正式任务 `Procesing()` 的首轮直接执行 RIGHT/BACK 校正，没有等待新鲜 IMU、回正或 BACK 后停稳；`while_task()` 每轮连续调用粗定位和正式任务两个状态机，两个状态机共享电机接口。

**修复**：
- 正式任务首轮增加 `Imu_Wait_Ready(1500)`、`Rotation(0)`、两段校正之间及 BACK 后各 `HAL_Delay(600)`。
- 增加 `BfsResetStart()`，校正完成后明确登记 BFS 起点 `(0,4)` 并清空旧路径。
- `while_task()` 改为粗定位阶段独占一轮主循环，只有 `CoarseStage == CoarseIdle` 时才执行正式任务。
- 修正 IMU DMA 接收长度：用 `IMU_CMD - DMA剩余计数` 得到已接收字节数，完整帧才能通过解析。

**验证**：正式入口回归测试、IMU 就绪测试全部通过；独立临时副本 Keil 编译 `0 Error(s), 3 Warning(s)`，警告仍为原有不可达 `break`。

## [2026-08-29] 粗定位到原料区后不再继续

**现象**：粗定位只能从启停区进入 BFS 并到达原料区，调整朝向后停在等待状态，无法自动走完二维码区、粗加工区、暂存区和回程。

**原因**：旧 `CoarseProcesing()` 在 `CoarseStationAlign` 后固定进入 `CoarseWaitArm`，没有测试模式的目标推进和完成收尾逻辑。

**修复**：粗定位测试改为 `二维码区(0,2) → 原料区(2,0) → 粗加工区(2,4) → 暂存区(4,2) → 所选出口`；四站分别调整车辆 yaw 为 `-90°、0°、180°、90°` 并停留 1000ms，回到出口后执行对应停止校正。旧单站实现用 `#if 0` 完整保留。

## [2026-08-29] BFS失败时仍可能读取无效路径

**现象**：任务坐标越界、目标是障碍物或不存在路径时，旧 `RunMap()` 仍会读取 `Path.path[1]`，存在轮子误动作或循环无法结束的风险。

**原因**：BFS 在坐标检查前直接访问地图；`RunMap()` 没有检查 `Path.path_len`、路径首尾和相邻性，也没有在失败后停止电机。

**修复**：BFS 先校验起终点坐标并在每次计算前作废旧路径；`RunMap()` 在任何运动前检查坐标、路径长度、首尾坐标和相邻步。校验失败立即停止四个电机并返回失败，粗定位状态机进入 `CoarseFaultBfsPath`，必须重新选择 `S1/S2` 后才能再次测试。

## [2026-08-29] 粗定位阶段仍保留旧正式流程调用入口

**现象**：粗定位状态为空闲时，主循环仍会调用旧 `Procesing()`；若旧任务状态被残留数据置为启动，可能绕开粗定位测试流程驱动车辆。

**原因**：`FORMAL_FLOW_ENABLE` 虽定义为 0，但此前没有用于主循环条件编译。

**修复**：`while_task()` 中的 `Procesing()` 改由 `#if FORMAL_FLOW_ENABLE` 控制；当前值为 0，旧正式抓取、识别和回航流程不会被编译进主循环调用路径。

## [2026-08-29] 新工程等待IMU后车辆完全不动

**现象**：旧工程可以发指令并运动但方向不稳定；当前粗定位工程点击测试后没有启动校正动作。

**原因**：USART3 RX 使用 `DMA_CIRCULAR` 接收固定11字节 HWT101 帧，旧接收处理用 DMA 剩余计数计算本次帧长。DMA回装或空闲中断时序下，`ImuCount` 可能不是11，`Imu_Get()` 不更新有效帧计数；启动校正中的 `Imu_Wait_Ready(1500)` 超时后进入 `CoarseFaultImuTimeout`，因此不会发送电机帧。

**修复**：保留旧计数代码注释，当前空闲中断按已确认的固定11字节帧设置 `ImuCount = IMU_CMD`，仍由 `Imu_Get()` 校验 `55 53` 帧头和校验和，并保留连续3帧就绪保护。新增 `Tests/imu_dma_frame_test.ps1` 回归测试。

**验证**：全部8组回归测试通过；独立临时副本 Keil 编译 `0 Error(s), 0 Warning(s)`。

## [2026-09-21] 机械臂舵机方向与渐变循环不一致

**现象**：舵机2、舵机3的弯腰/抬臂动作读数增减与实测方向相反；舵机4打开/闭合渐变循环方向错误，部分循环因负数差值配合 `uint8_t` 完全不执行。

**原因**：未按实测方向统一动作表达式：舵机2靠近地面读数增加、舵机3靠近地面读数减小、舵机4打开读数增加；旧循环用无符号变量表示递减过程，且舵机3回程使用了负差值上限。

**修复**：保留旧实现注释，新增方向明确的动作：观察到抓取时舵机2增加、舵机3减小；抓起和放置回观察时舵机2减小、舵机3增加；舵机4打开递增、闭合递减；放置回搬运时舵机3改为有符号递增循环。

**验证**：Keil 工程编译 `0 Error(s), 2 Warning(s)`；剩余警告为原有观察/搬运角度相等导致的无效循环比较。

## [2026-09-22] 舵机姿态终点与实测方向冲突

**现象**：抓取、放置和回搬运动作中，舵机2/3的中间角度与终点角度方向不一致；`Servo_Close_To_Plate()` 中舵机3出现 `18 -> 66 -> 20` 的反向跳变。

**原因**：舵机2靠近地面应增加、舵机3靠近地面应减小，但原姿态宏为 `JOINT2_CATCH=212`、`JOINT3_CATCH=141`，与观察姿态方向相反；多个函数用固定角度和无符号差值，导致循环不执行或跨姿态跳变。

**修复**：将粗略姿态关系调整为舵机2抓取/贴盘角增加、舵机3抓取/贴盘角减小；抓取、抬臂、进入盘子、下降贴盘、回搬运和回观察动作均改为从宏起点向宏终点单调变化；旧实现保留为注释。

**验证**：Keil 工程编译 `0 Error(s), 5 Warning(s)`。剩余 2 条为观察/搬运角相等导致的无效循环比较，另 3 条为 `move.c` 原有不可达 `break`。
